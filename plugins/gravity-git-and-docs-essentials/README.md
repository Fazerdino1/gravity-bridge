# Git, Documentation & Planning Essentials (`gravity-git-and-docs-essentials`)

Essential reviewed workflows for Conventional Commits, README generation, code review, CommonMark Markdown, and implementation planning.

## Install in Google Antigravity

Copy this folder into `~/.gemini/config/plugins/` and restart Antigravity:

```sh
cp -r plugins/gravity-git-and-docs-essentials ~/.gemini/config/plugins/
```

## Included items

- `skills/conventional-commit`
- `skills/create-readme`
- `skills/review-and-refactor`
- `rules/markdown.md`
- `agents/implementation-plan`
