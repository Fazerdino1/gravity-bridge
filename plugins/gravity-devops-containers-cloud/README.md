# DevOps, Docker, Kubernetes & CI/CD (`gravity-devops-containers-cloud`)

Best-practice rules and skills for multi-stage Dockerfiles, Kubernetes deployments, GitHub Actions CI/CD, and cloud architecture.

## Install in Google Antigravity

Copy this folder into `~/.gemini/config/plugins/` and restart Antigravity:

```sh
cp -r plugins/gravity-devops-containers-cloud ~/.gemini/config/plugins/
```

## Included items

- `rules/containerization-docker-best-practices.md`
- `rules/kubernetes-deployment-best-practices.md`
- `rules/kubernetes-manifests.md`
- `rules/github-actions-ci-cd-best-practices.md`
- `skills/multi-stage-dockerfile`
- `skills/devops-rollout-plan`
- `agents/aws-principal-architect`
- `agents/azure-principal-architect`
