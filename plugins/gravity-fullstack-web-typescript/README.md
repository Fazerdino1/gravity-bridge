# Full-Stack Web & TypeScript (`gravity-fullstack-web-typescript`)

Rules, skills, and personas for modern Next.js, Node.js, Vitest, Playwright TypeScript, and web accessibility.

## Install in Google Antigravity

Copy this folder into `~/.gemini/config/plugins/` and restart Antigravity:

```sh
cp -r plugins/gravity-fullstack-web-typescript ~/.gemini/config/plugins/
```

## Included items

- `rules/nextjs.md`
- `rules/nextjs-tailwind.md`
- `rules/nodejs-javascript-vitest.md`
- `rules/playwright-typescript.md`
- `rules/a11y.md`
- `skills/playwright-generate-test`
- `skills/playwright-explore-website`
- `agents/typescript-mcp-expert`
- `agents/vuejs-expert`
