# TDD Cycle & System Architecture (`gravity-tdd-and-architecture`)

Red-Green-Refactor TDD personas, API breaking-change detection, and system architecture planning.

## Install in Google Antigravity

Copy this folder into `~/.gemini/config/plugins/` and restart Antigravity:

```sh
cp -r plugins/gravity-tdd-and-architecture ~/.gemini/config/plugins/
```

## Included items

- `skills/api-breaking-change-detector`
- `skills/create-implementation-plan`
- `agents/tdd-red`
- `agents/tdd-green`
- `agents/tdd-refactor`
- `agents/se-system-architecture-reviewer`
- `agents/project-architecture-planner`
