# Python, Testing & AI Engineering (`gravity-python-and-ai`)

Python testing, Playwright Python, LangChain, and MCP server expertise for Antigravity.

## Install in Google Antigravity

Copy this folder into `~/.gemini/config/plugins/` and restart Antigravity:

```sh
cp -r plugins/gravity-python-and-ai ~/.gemini/config/plugins/
```

## Included items

- `rules/langchain-python.md`
- `rules/playwright-python.md`
- `skills/pytest-coverage`
- `agents/python-mcp-expert`
- `agents/python-notebook-sample-builder`
