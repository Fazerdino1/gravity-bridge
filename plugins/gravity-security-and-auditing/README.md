# Security, OWASP & Code Auditing (`gravity-security-and-auditing`)

Security rules, MCP security audit skills, and SAST/SCA architecture review personas.

## Install in Google Antigravity

Copy this folder into `~/.gemini/config/plugins/` and restart Antigravity:

```sh
cp -r plugins/gravity-security-and-auditing ~/.gemini/config/plugins/
```

## Included items

- `rules/security-and-owasp.md`
- `rules/ai-prompt-engineering-safety-best-practices.md`
- `skills/security-review`
- `skills/mcp-security-audit`
- `skills/mcp-implementation-security-review`
- `agents/se-security-reviewer`
- `agents/sast-sca-security-analyzer`
