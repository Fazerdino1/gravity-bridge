# Sicherheitsrichtlinie

**Sprachen:** [English](SECURITY.md) · [Français](SECURITY.fr.md) · [Español](SECURITY.es.md) · **Deutsch**

## Warum das wichtig ist

Skills, Regeln und Personas sind Anweisungen für einen KI-Agenten und können Befehle auf dem System des Benutzers ausführen. Daher wird jede Ressource mit `npm run validate` geprüft und alle eingebetteten Skripte werden in [docs/scripts-security-audit.md](docs/scripts-security-audit.md) auditiert.

## Eine Sicherheitslücke melden

Bitte **erstellen Sie kein öffentliches Issue**. Nutzen Sie die private Sicherheitsmeldung auf GitHub (Reiter *Security* → *Report a vulnerability*) oder schreiben Sie an [fazerdinotheck@outlook.fr](mailto:fazerdinotheck@outlook.fr).
