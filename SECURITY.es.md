# Política de seguridad

**Idiomas:** [English](SECURITY.md) · [Français](SECURITY.fr.md) · **Español** · [Deutsch](SECURITY.de.md)

## Por qué es importante

Los skills, reglas y personas son instrucciones para un agente de IA y pueden hacer que el agente ejecute comandos o edite archivos en la máquina del usuario. Por ello cada recurso se valida con `npm run validate` y los scripts incluidos se auditan en [docs/scripts-security-audit.md](docs/scripts-security-audit.md).

## Informar de una vulnerabilidad

Por favor, **no abra un issue público**. Utilice el reporte privado de vulnerabilidades de GitHub (pestaña *Security* → *Report a vulnerability*) o escriba a [fazerdinotheck@outlook.fr](mailto:fazerdinotheck@outlook.fr).
